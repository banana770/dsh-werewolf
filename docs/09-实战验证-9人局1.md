## 一、这局用的是哪一版剧本（版本指纹）

从主会话系统提示词里逐一查找我历次加进去的段落标记：

| 加固段落 | 加入批次 | 本局是否存在 |
|---|---|---|
| 三·补 狼队协商协议 | 第 1 批 | ✅ 有（24 处） |
| 同时收票 / 一次公布 | 第 1 批 | ✅ 有 |
| **输出纪律**（夜间行动不进正文等） | **第 2 批** | ✅ **有** |
| 逐字播报原文（竞选发言修复） | 第 3 批 | ✅ 有（5 处） |
| 教练式输出禁令 / 不当军师 | 第 4 批 | ❌ 无 |
| 播报时机 | 第 4 批 | ❌ 无 |
| 观众视角需先问 | 第 4 批 | ❌ 无 |
| 工作步骤展示提醒 | 第 5 批 | ❌ 无 |

**结论**：本局 = **第 3 批版本**。恰好带着"竞选发言修复"，但**没带"教练禁令"** —— 完美的对照样本。

### 泄漏扫描的命中项，逐条核对后全部合法

`刀 N 号` / `毒 N 号` / `验 N 号` / `悍跳` / `金水` 共 14 处命中，全部落在：

- **玩家发言原文**（如 3 号说「我验的是 7 号，金水…他这是标准悍跳手法」）—— 转述，正常
- **真人自己**的行动选项（他是女巫，上帝给他「用解药自救 / 毒 3 号」的回复示例）
- **终局复盘**（游戏已结束，允许公开）

→ **没有一处是上帝自己泄露的。**

## 四、⚠️ 一个反直觉的发现：第 4 批的「教练禁令」是多余的

六人局1 里上帝大量输出「关键提示 / 建议你做的事」，我据此加了第 4 批的**教练式输出禁令**。

**但 9 人局1 没有这条禁令，却零命中。**

→ 说明真正起作用的是**第 2 批的「输出纪律」**（"你的回复正文是给真人看的播报，不是工作日志" + 那张错误示范）。它在压住夜间泄漏的同时，**顺带把教练式输出一起压住了**。

**含义**：

| | |
|---|---|
| 好的一面 | 一条规则解决了两类问题，说明"输出纪律"这条约束抓得准 |
| 代价 | 第 4 批那 ~800 字符是冗余，而它会被 **8 个玩家每轮各背一遍** |
| 是否回滚 | **暂不回滚**。一局干净不足以做统计结论，保留作纵深防御。但这是 persona 瘦身的候选 |

## 五、新发现的小瑕疵（已修）

**夜间播报重复且措辞错误**：

```
--- [3] ---  🌙 夜间流程进行中，请稍候……
--- [4] ---  🌙 天黑请闭眼 —— 夜间流程已走完，现在轮到你了。
```

- 「天黑请闭眼」整夜说了两次
- **「夜间流程已走完」是错的** —— 此时才轮到女巫（第 3 顺位），后面还有预言家

**已修**：在第三节写明「天黑请闭眼整夜只说一次」+ 禁止说「夜间流程已走完」。
