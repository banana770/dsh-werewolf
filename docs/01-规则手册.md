# 狼人杀 · 规则手册（引擎口径）

> **本文档是引擎的唯一规则依据。** 代码只实现本文档；文档没写的，代码不许自作主张。
> 所有存在流派分歧的规则，一律在第 6 节"裁决矩阵"里定档，并标出对代码的影响面。

---

## 1. 阵营与胜负

| 阵营 | 组成 | 胜利条件 |
|---|---|---|
| 好人阵营 | 神职 + 平民 | 放逐或杀死全部狼人 |
| 狼人阵营 | 狼人（含狼王/白狼王等变体） | **屠边**：杀光全部神职 **或** 杀光全部平民 |

**屠边 vs 屠城**（可配置，默认屠边）：

- **屠边**（主流）：神职全灭 → 狼胜；平民全灭 → 狼胜。剩最后 1 神 1 民 1 狼时，狼需再杀一人。
- **屠城**：所有好人全灭 → 狼胜。

**终局判定时机**：每次结算完死亡后、进入下一阶段前判定。若同时满足双方条件，**好人优先**（即若最后一狼与最后好人同归于尽，判好人胜）。

## 2. 角色全集

### 2.1 狼人阵营

| 角色 | 夜晚 | 技能 | 限制与判定 |
|---|---|---|---|
| **狼人** | 第 2 顺位 | 与同伴共同选择一名玩家刀杀；可**空刀**（不刀任何人）；可**自刀** | 多名狼意见不一致时：默认**少数服从多数**，平票则取**最早提交**的目标（可配置为随机）；空刀需全员同意，默认**任一狼可选空刀即空刀** |
| **狼王** | 同狼人 | 额外：被投票放逐或被刀杀时，可开枪带走一人 | **被女巫毒死不能开枪**（R3 同猎人） |
| **白狼王** | 同狼人 | 额外：白天**自爆**时可带走一人 | 自爆带人后立即入夜 |

**狼人互认**：首夜开始前，全部狼人互相得知队友身份（线上由系统直接告知；面杀由法官手势）。

### 2.2 神职

| 角色 | 夜晚顺位 | 技能 | 限制与判定 |
|---|---|---|---|
| **守卫** | **1** | 每晚守护一名玩家（含自己，R4），当晚免疫狼刀 | ① **不能连续两晚守同一人**；② **同守同救必死**（R5）：若守卫守了 A 且女巫同时救 A，A 依然死亡；③ 守卫不挡毒药 |
| **预言家** | 4 | 每晚查验一名玩家，法官告知**好人 / 狼人** | 无消耗；查验结果只告知预言家本人 |
| **女巫** | 3 | 全局**解药 1 瓶** + **毒药 1 瓶** | ① 不能同一夜使用双药（R2）；② 首夜可自救（R1），之后不可自救；③ 解药只在**知道当晚死讯**后决定是否使用；④ 毒药无视守卫 |
| **猎人** | 5 | 死亡时可开枪带走一人 | **被女巫毒死不能开枪**（R3）；被放逐、被刀杀可开枪 |
| **白痴** | 6 | 被**投票放逐**时翻牌免死 | ① 翻牌后**失去投票权**；② 可继续发言；③ 被刀杀/被毒杀时正常死亡，无免死 |

**夜晚顺位说明**：守卫必须在狼人之前（否则无法决定守护目标）；女巫必须在狼人之后（需要知道死讯）；预言家顺序无结算耦合，放在女巫后是主流习惯。

### 2.3 平民

无技能。只有发言与投票权。

### 2.4 本期不实现的变体（列入 backlog）

丘比特 / 盗贼 / 混血儿 / 长老 / 骑士 / 潜行者 / 魔术师 / 狐狸 / 禁言长老。

## 3. 板子配置

板子 = `{id, 名称, 人数, 角色集合, 规则开关}`。

| 板子 id | 名称 | 人数 | 狼 | 神职 | 平民 |
|---|---|---|---|---|---|
| `novice-6` | 新手局 | 6 | 2 狼人 | 预言家、女巫 | 2 |
| `standard-9` | 标准局 | 9 | 3 狼人 | 预言家、女巫、猎人 | 3 |
| `classic-12` | **预女猎白** | 12 | 4 狼人 | 预言家、女巫、猎人、白痴 | 4 |
| `guard-12` | 预女猎守 | 12 | 4 狼人 | 预言家、女巫、猎人、守卫 | 4 |
| `wolfking-12` | 狼王守卫 | 12 | 3 狼人 + **1 狼王** | 预言家、女巫、猎人、守卫 | 4 |

**Schema（引擎加载用）**：

```ts
interface Board {
  id: string
  name: string
  players: number
  roles: RoleId[]          // 长度必须 === players
  rules: RuleFlags         // 见第 6 节，未指定则取默认
}
```

**校验规则**：`roles.length === players`；狼人阵营数量 ≥ 1；好人 ≥ 1；未知 RoleId 直接拒绝加载。

## 4. 夜晚流程（严格顺序）

法官按顺位依次唤醒，**未使用的角色是否睁眼**按板子决定（不在板子里的角色直接跳过）。

| 顺位 | 角色 | 法官动作 | 输入 | 输出 |
|---|---|---|---|---|
| 0 | 全部 | 宣布"天黑请闭眼" | — | 进入夜晚 |
| 1 | 守卫 | 睁眼，选择守护对象 | `guard: seatId \| null` | 守护记录（不公布） |
| 2 | 狼人 | 睁眼，互认队友，共同选择目标 | `kill: seatId \| null` | 狼刀目标（不公布） |
| 3 | 女巫 | 睁眼，**先被告知今晚谁倒牌**，再决定是否用药 | `heal: boolean`, `poison: seatId \| null` | 用药记录（不公布） |
| 4 | 预言家 | 睁眼，选择查验对象，法官单独告知结果 | `check: seatId` | → 私聊该玩家"X 号是好人/狼人" |
| 5 | 猎人 | 睁眼，法官确认其状态（是否能开枪） | 无 | 状态标记 |
| 6 | 白痴 | 睁眼，法官确认其身份 | 无 | 状态标记 |
| 7 | 全部 | 宣布"天亮了" | — | 进入白天结算 |

### 4.1 夜晚结算算法（核心，必须与实现逐行一致）

```
输入：guard?, kill?, heal?, poison?, (板子规则开关)

D = {}                      # 今晚死亡集合
# --- 步骤 1：狼刀结算 ---
if kill != null:
    if guard == kill and heal == true:
        D.add(kill)         # R5：同守同救 → 仍死
    elif guard == kill:
        pass                # 守卫生效，免刀
    elif heal == true:
        pass                # 解药生效，免刀
    else:
        D.add(kill)

# --- 步骤 2：毒药结算（无视守卫） ---
if poison != null:
    D.add(poison)

# --- 步骤 3：死亡原因标记（决定能否开枪） ---
deathCause[seat] = 'wolf' | 'poison' | 'vote'

# --- 步骤 4：判定 ---
结算死亡 → 检查胜负 → 生成天亮公告（只报"平安夜"或"N 号倒牌"，绝不报死因）
```

**公告口径**：

- 无人死亡 → `昨晚是平安夜。`
- 一人死亡 → `昨晚 N 号倒牌。`
- 多人死亡 → `昨晚 N 号、M 号倒牌。`
- **绝不公布死因、绝不公布用药、绝不公布守护。**

## 5. 白天流程

### 5.1 第一天：警长竞选

| 步骤 | 说明 |
|---|---|
| 上警报名 | 存活玩家自愿报名（狼可上可不上）；此阶段不发言 |
| 竞选发言 | 按报名顺序依次发言，可**退水**（退出竞选） |
| 投票 | 未上警的存活玩家投票（可弃票） |
| 当选 | 得票最多者当选；**平票 → 平票者 PK 发言 → 重新投票**；再次平票 → **警徽流失**（本局无警长） |

**警长权限**：投票权重 **1.5 票**（R7）；决定每天发言顺序（死左/死右、顺序/逆序）；死亡时可**移交警徽**给任意存活玩家或**撕警徽**（R8）。

### 5.2 发言阶段

- 顺序由警长决定；无警长时默认从**死左**（死者左手位）开始。
- 每人一次发言，**限时**（默认 60 秒 / 或 300 字）。
- 发言内容自由：报身份、报查验/用药/守护、评价前置发言、给出投票意向。
- **自爆窗口**：狼人可在自己发言前自爆 → 立即入夜，无遗言（R8 关闭时不可移交警徽）。

### 5.3 投票放逐

| 情形 | 处理 |
|---|---|
| 最高票唯一 | 该玩家被放逐，留遗言，入夜 |
| 最高票平票 | 平票者依次 **PK 发言** → 其余存活玩家**重新投票** |
| 再次平票 | **无人出局**（平安日），直接入夜 |
| 全员弃票 | 无人出局 |

**投票权**：存活玩家均有；白痴翻牌后**无**（R 见 2.2）；警长 1.5 票。

### 5.4 遗言

| 死亡方式 | 遗言（默认 R6 = 仅首夜） |
|---|---|
| 首夜被杀/被毒 | ✅ 有 |
| 第二夜及以后被杀/被毒 | ❌ 无 |
| 被投票放逐 | ✅ 有 |
| 自爆的狼人 | ❌ 无 |

## 6. 裁决矩阵（定档表）

**这是本文档最重要的表。** 每一行都是引擎里一个显式的规则开关。

| # | 争议点 | 定档 | 备选 | 影响面 |
|---|---|---|---|---|
| R1 | 女巫首夜能否自救 | **能** | 不能 | `night.resolve` 步骤 1 的解药判定 |
| R2 | 女巫能否同夜双药 | **不能** | 能 | 夜晚行动校验：`heal && poison` → 非法 |
| R3 | 猎人/狼王被毒能否开枪 | **不能** | 能 | `deathCause === 'poison'` → 剥夺开枪 |
| R4 | 守卫能否守自己 | **能** | 不能 | 守卫行动校验 |
| R5 | 同守同救 | **死** | 活 | `night.resolve` 步骤 1 的分支 |
| R6 | 夜晚死亡遗言 | **仅首夜** | 都有 / 都无 | 遗言资格判定 |
| R7 | 警长投票权重 | **1.5 票** | 1 票 | 计票函数 |
| R8 | 自爆后能否移交警徽/指刀 | **能** | 不能 | 自爆处理分支 |
| R9 | 狼人刀人意见不一致 | **多数决，平票取最早提交** | 随机 / 首个 | 狼人行动聚合 |
| R10 | 空刀 | **任一狼可选，需全员同意** | 单狼即可 | 狼人行动聚合 |

> 每一项在 `RuleFlags` 里是一个布尔/枚举字段，默认值如"定档"列。**引擎必须对每个开关都有单测。**
